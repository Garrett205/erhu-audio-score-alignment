DP3 landmarks: `same_note_group_reassign` handles matched repeated-pitch groups;
`reassign_repeated_pitch_conflicts` reopens mixed-status runs;
`anchor_terminal_suffix_to_observed_black` handles the final-measure suffix.
The ordinary recovery functions retain their ownership and ambiguity checks.
Mel uses the unchanged `candidates` function with `BEST_ADMISSIBLE=True`; its
runner-up margin is zero, while ordinary DP3 margins are not changed globally.

See `SOURCE_PROVENANCE.json` for exact source files and definition comparisons.
