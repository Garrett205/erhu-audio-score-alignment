# Data availability

The repository contains code/configuration only. It contains no public dataset
files, private recordings, MusicXML, human review material, signed consent forms
or checkpoints. CCOM-HuQin must be obtained independently, subject to its terms:
https://doi.org/10.5334/tismir.146

Private score-following recordings are not publicly distributed due to
participant-consent/privacy restrictions. No access entitlement is implied.
No complete second-rater event-level label table was retained in the located
paper evidence. Code cannot reconstruct missing human judgments.

The paper's retained CCOM population is 18 recordings, 198,536 reference frames,
164,183 reference-voiced frames and 34,353 reference-zero frames. The dataset's
exact downloaded release identifier is not known from the local freeze.
The twelve private performances and 1,229 alignment events are not shipped.
